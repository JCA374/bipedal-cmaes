Lesson 2 of 8

A policy is just numbers

The walker's "brain" is a small neural network: 932 numbers and two layers of arithmetic. This lesson takes it apart, so that in lesson 3 "learning" can mean something very concrete: changing those 932 numbers.

After this lesson you can
  • compute what one neuron does, by hand;
  • explain what the hidden layer adds compared with a plain linear controller;
  • count the parameters of a network, and explain why training is a search through a 932-dimensional space.

1One neuron

A neuron takes a list of inputs x, multiplies each by its own weight w, adds them up, adds a bias b, and squashes the result with tanh:

z = w₁x₁ + w₂x₂ + … + w₂₄x₂₄ + b     y = tanh(z)

tanh is an S-shaped curve. Small z passes through almost unchanged; large z gets squashed to ±1. That's handy: motor commands must be in [−1, 1], and tanh guarantees it. A positive weight means "this input pushes me up"; a negative weight means "this input pushes me down"; the bias sets the default.

Example: a neuron with weight +2 on hull angle and −1.5 on leg 1 contact fires positive when the body tilts forward and leg 1 is in the air.

2The walker's network

The network has three layers of neurons:

  • 24 inputs: the observation from lesson 1 (not really neurons, just the numbers);
  • 32 hidden neurons: each looks at all 24 inputs (24 weights + 1 bias);
  • 4 outputs: each looks at all 32 hidden neurons (32 weights + 1 bias) and gives one motor command.

Every step, the walker runs this exact calculation once: action = tanh(W2 · tanh(W1 · obs + b1) + b2). It has no memory between steps. On a laptop that takes about a microsecond.

3Why a hidden layer?

Without the hidden layer, each output would be tanh(w · obs + b): a linear controller, 100 numbers in total. It can only express rules like "push the hip harder the more you tilt". It can't express "if leg 1 is on the ground and I'm tilting forward, swing leg 2", because that depends on a combination of inputs.

The hidden neurons are learned features: each one detects some combination of inputs, and the outputs combine those detections. One hidden layer of tanh neurons can, in principle, approximate any smooth controller. This project also has a hard rule that the policy must have at least one hidden layer (asserted in the code and the tests), because a linear policy would be a different, easier comparison.

A design choice: the shape is fixedMy previous project used NEAT, which evolves the network's shape as well as its weights. It ended up with 4 hidden neurons and 30 connections, and kept pruning capacity away. Here the shape is fixed at 24→32→4, and we only search for the weights. That keeps the problem simple: one list of 932 numbers.

4932 numbers = one point

Write all the weights and biases in one long list, θ ("theta"), always in the same order. That list is the policy: save it to a file (7 KB) and you have saved the walker.

θ, the whole walker in one strip

Each thin stripe is one of the 932 numbers. Press "nudge" to add a little random noise, which is exactly what the training algorithm does to make new candidates. The orange marks below the strip show which numbers moved, and the network above reacts.

Now picture a space with 932 axes, one per number. Every possible walker is a single point in that space. Some points are walkers that fall immediately, some shuffle, and somewhere there are points that walk to the finish. Give each point a height, its fitness: the average reward it earns over a few tracks. Training means finding a high point in this 932-dimensional landscape.

Here's the catch: we can evaluate a point (run the walker and read off the reward), but the physics simulator can't tell us which direction is uphill. Falls are sudden, reward is noisy, and the simulator isn't differentiable. Lesson 3 is about climbing a landscape you can only sample.

Check yourself

1. How many numbers would a 24 → 16 → 4 network have?

Weights plus biases: 384 + 16 + 64 + 4 = 468. Every non-input neuron has one bias.

2. Why use tanh on the outputs?

The environment expects actions in [−1, 1]; tanh maps any number into that range. It doesn't add memory: the network still only sees the current step.

3. What does "training" change in this project?

The shape (24→32→4) and the input scaling are fixed. Training is a search for θ.
